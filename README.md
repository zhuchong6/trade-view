# AB 策略监控 · Trade View

Chrome MV3 插件。只做一件事：**按实时价格核对 A 仓买卖点、B 仓建仓档位**。

## 两套策略

| 仓 | 标的 | 买入 | 卖出 / 再平衡 |
| --- | --- | --- | --- |
| A 波段仓 | 512890 | 收盘价 < MA60 × 0.97 | ≥ MA60 × 1.05 或浮盈 ≥ 10%，切回 511260 |
| A 停泊 | 511260 | 闲置资金分批买入 | A 仓买点出现时卖出 |
| B 现金流仓 | 515450 | PE 分位分档（50% / 80% / 100%）或回踩 MA120 | 建好后长期持有，分红优先还月供 |

## 价格口径

- 界面上的数字都是**行情里的实时价**，可以直接和券商对照。
- 均线和信号基于**前复权**日 K：前复权的最后一天等于真实成交价，历史价格被统一缩放，所以 MA60 天然就在现价坐标里，不需要再乘什么因子。
- 不用后复权的原因：后复权会把累计分红算进价格（512890 约是现价的 2 倍），看到的 2.5 和券商里的 1.26 对不上，容易误判。
- 浮盈用前复权价算，已包含分红收益。录完买入后若再分红，前复权历史会整体缩放，插件用「录入日价格 ÷ 录入时价格」自动校正成本。
- 只认收盘：盘中触及阈值标「待确认」，不推送通知、不打角标。

## 数据源

| 顺序 | 接口 | 说明 |
| --- | --- | --- |
| 1 | `web.ifzq.gtimg.cn` 腾讯 | 区间模式 `qfq` 前复权，**三位小数**，但不含当天 |
| 1b | `qt.gtimg.cn` 腾讯快照 | 补上当天那根 K 线，同样是三位小数 |
| 2 | `push2his.eastmoney.com` 东财 | `fqt=1`，腾讯失败时自动切换 |

> 腾讯只传「条数」时会把前复权价裁成两位小数（1.26），必须传起止日期才给三位小数（1.261）；
> 而区间模式不含当天，所以额外用实时快照补最后一根。

- 两个源都拿不到时，界面会显示**上一次缓存**并标注时间，不影响已有的记录。
- 已经遇到过：东财域名在部分网络下直接不可达（`Failed to fetch`），所以默认走腾讯。
- PE-TTM 分位没有免鉴权接口，**手动录入**，插件不编造估值。

## 界面

**弹窗**（点图标）—— 两张卡：

- A 仓：大字实时价、涨跌幅、MA60 / 买入线 / 卖出线 / 距买点、一句结论
- B 仓：实时价、PE 分位、MA120、偏离、本档可投金额、一句结论

**监控台**（弹窗底部按钮）—— 同样的两张卡，加：

- 记一笔 / 记卖出，自动切换 A 仓状态、累加 B 仓已投金额
- PE 分位录入与四档色条
- 交易记录表
- 参数：A/B 计划资金、买入系数、卖出系数、止盈线

## 安装

1. `chrome://extensions/` → 打开开发者模式
2. 「加载已解压的扩展程序」→ 选择本目录
3. 点图标打开弹窗，进「监控台」设置资金与参数

## 权限

- `storage`：配置（sync）与记录（local）
- `alarms`：每 30 分钟巡检
- `notifications`：买卖信号提醒
- `host_permissions`：腾讯、东财行情域名

## 免责

工具只按既定规则算数，不判断该不该买。数据为公开行情，可能存在延迟或缺失，投资决策与风险由使用者自负。
